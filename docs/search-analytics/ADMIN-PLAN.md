# 阶段五实施计划（2026-11-28）

1. 共享包新增版本化Admin查询/命令契约与访问层。按90天以内、每页100以内、排序白名单约束查询；概览提供今日/昨日/7/30/90天，趋势及来源/语言分布。身份去重只在留存范围内可用，长期展示身份日；关键词得分明确为当前发布快照的得分，不伪造全历史排名。
2. 配置及规则写入复用规范化/安全验证，D1事务绑定版本CAS与匿名管理员审计；规则上限500。审核变更立即使公开版本失配，随后受租约保护的后台刷新。人工批准不能恢复此前未具资格的贡献或绕过安全门槛。

影响：packages/search-analytics、apps/admin和专题文档；不更改核心迁移、Pagefind、SEO或Bot缓存。无需新云资源，不自动配置现有资源。Admin使用已规划ANALYTICS_DB/PUBLIC_CACHE，审计HMAC复用现有SETTINGS_KEY并隔离用途域（必须至少32字符），不记录原始管理员身份。

资源：只在管理员访问时产生分页统计读取；写操作约1条业务记录和1条审计记录（含索引/触发器额外写入），人工刷新复用阶段四成本。90天关键词分组及条件搜索可能扫描所选时间范围数据，须实测并设最大分页/窗口；无自动轮询。禁止将SQL meta当完整账单。

风险：统计DB不可用时后台显示不可用，正常搜索保持隔离；审核会暂时空榜，刷新失败保留安全失效；waitUntil不是可靠队列，失败可由任务日志/人工刷新恢复。已有部署开关默认关闭，数据库配置不能越过部署限制。无需新增迁移；生产接入仍须独立授权。

验收：八视图可用且真实数据驱动；权限、口径、CAS、审计和严格撤回有测试；所有规定检查完成并记录结果；独立堆叠草稿PR；不合并/迁移/部署。
