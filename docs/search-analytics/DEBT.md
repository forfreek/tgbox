## 阶段五收尾发现：关闭与回滚推荐路径（P1，上线前必修）

证据：apps/web/src/components/search/SearchDialog.tsx visibleWords在publicationEnabled=false时直接使用hotKeywords，绕过D1审核gate。当前默认关闭兼容旧推荐的实现，在统计从未启用/未审核前不意味着生产已暴露新规则；但未来启用后编译关闭或回滚到静态推荐代码，可能重新公开隐藏词。该路径未在本Admin节点改动，阶段六必须修正并测试编译开关关闭、API失败、旧版本回滚等状态；未解决不得启用生产。建议新前端关闭态安全空榜，不再拿未审核静态推荐回退；冷启动推荐统一走已审核API。部署回滚不得恢复旧静态词，需明确前端与Worker回滚矩阵。
