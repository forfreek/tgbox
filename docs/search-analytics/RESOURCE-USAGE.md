# 搜索分析资源实测与估算

阶段三入口量级：见COLLECTION.md。无KV读取；浏览器每候选一个POST（挑战另计），会话可以在事件内签发；1万全新网站会话+事件按夹具约79万读/28万写/日，规则、安全采样和清理额外。核心验证另计，2字符LIKE最坏扫描必须在生产启用前压测，3秒超时不等于取消SQL。Bot复用结果无额外核心读；原生边缘拒绝不进入D1，近似限流不是严格全局预算。

2026-11-28。用户已明确使用付费版；按付费容量与合理防刷需求设计，不按免费额度刻意压低阈值。默认全局有效事件10000/日保持，允许后台调整1–100000/日，不自动修改任何生产配额。

## 实测范围

Miniflare/Workers池的独立统计D1 meta，空库/当前迁移下固定夹具；包含库内成功查询，不含入口认证之前的边缘请求、注入的核心FTS、KV/Cron/Admin或后续清理。失败查询不一定提供完整计费meta，usageComplete=false表示只有部分信息。不是生产账单或CPU实测。

## 日/月量级

- 每日10000个新身份事件：约19万–22万统计库写入行/日，按30天约570万–660万/月。
- 若主要为同身份同日重复：约11万写入行/日；新来源/语言维度或新词会增加记录。
- 签发1000个匿名会话：额外约6000写入行/日。签发预算与事件预算独立，合理调节防止批量身份创建。
- 规则较少时核心统计读取约每事件几十行；500条规则夹具约2054行，10000事件约2054万读取行/日。这是上限规则场景，不推断为典型生产值。
- 供应商验证最多一次/已预留token，独立日预算默认500、每身份3/分钟、每IP5/分钟；后台可在合理范围内调节日预算。
- 安全抽样每天最多100个样本，计数不携带关键词/身份，额外写入有限；被拒绝的抽样保留读取但不写入。
- API拒绝同样占Worker请求；边缘限流适配在阶段三实施，不能假称原生近似限流提供严格全球计数。
- 90天聚合行数取决于每日不同词/来源/语言组合；身份事实和receipt只保留8天，清理写入在阶段四测量。

正常负载不因旧免费额度而降低缓存或搜索体验。独立数据库隔离数据与查询故障，但账户级配额和Worker可用性仍共享；监控和部署参数按实际付费配置管理，不把库隔离宣传为账户级故障隔离。

Node本机规范化10000次约71.4ms墙钟，仅证明轻量字符归并；不是Workers CPU/冷启动保证。生产分地区CPU和网络延迟留待阶段六。
