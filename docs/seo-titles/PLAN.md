## 节点一

- 简体 Title 为「搜索 Telegram 频道、群组与机器人」，繁体为「搜尋 Telegram 頻道、群組與機器人」，英文为「Telegram Directory: Channels, Groups & Bots」。统一由现有 Seo.astro 追加当前站名 TGsearch 一次。本节点沿用项目现有品牌大小写。
- H1 表达查找对象，原有大字品牌改为普通段落，保留视觉和读屏名称。
- 摘要保留 {total}，来自 getSiteData().stats.total。部分频道才有预览，成员资料使用可用性限定。
- 简体、繁体、英文独立维护首页核心文案。繁体继续通过既有最终 HTML 转换流程。
- 涉及 ui-seo.ts、ui-home.ts、HomeHero.astro，以及现有 SEO 单元与构建回归。复用 homeSeo、快照、共享 SEO 和 Pagefind。

## 验证与回滚

1. 动态摘要对 0、28、1969 的统计输入填充，最终构建摘要与快照总数、OG 和 JSON-LD 一致。
2. 三语首页单个可见 H1，Title 和首屏语义一致，Canonical、语言替代链接与 sitemap 维持正确对应。
3. 执行 web 基础测试、Astro 类型检查、改动文件 Biome；构建后在桌面和移动视口验证搜索打开、查询、跳转详情及 Escape 关闭。
4. 独立 PR 的 CI 通过后交付。回滚使用本节点提交的 revert，下一次按授权发布恢复文案。
