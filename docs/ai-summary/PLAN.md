| 输入情况 | 期望处理 | 再处理条件 |
| --- | --- | --- |
| 仅名称、用户名、分类或标签 | skipped，原因 no_substantive_evidence，保留现有摘要 | 实质输入或规则版本变化 |
| 只有广告、联系方式、链接或表情 | 清理后复查，无实质资料则 skipped | 清理后的实质输入变化 |
| 简介明确、频道无公开帖子 | 可生成限于简介的短说明 | 简介变化或新增有用帖子 |
| 简介空、频道有明确公开帖子 | 可描述可见样本，使用“近期公开内容涉及”等范围限定 | 证据样本变化，或出现明确简介 |
| 群组简介模糊、无聊天样本 | skipped，不推断成员质量、讨论频率或活跃程度 | 简介补齐 |
| 机器人无明确功能说明 | skipped，不从名称、分类或启动参数猜功能 | 明确功能资料补齐 |
| 简介与帖子矛盾或歧义 | needs_review，原因 source_conflict，批准前用现有摘要 | 人工复核或来源变化 |
| 限流、超时或解析异常 | retry_wait，保留已有资料并有限退避 | 重试到期，耗尽后转 failed |

原因码在步骤一、二确认。任务执行状态与内容审核状态分开保存，needs_review 是候选审核状态。预检 skipped 不调用模型，模型返回 insufficient 时已产生的推理记录仍计入用量。人工可以补充独立摘要，但发布时需保留依据并遵守编辑锁定及审计规则。
