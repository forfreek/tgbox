# AI 摘要模块设计

2026-11-22 架构设计快照。步骤二和步骤三已按用户逐步授权实施，实际契约见 CONTRACTS.md，实际数据与任务实现及相对本设计的调整见 [TASKS](TASKS.md)。以下未来阶段字段和参数仍按节点验证。真实链路按需查 [AUDIT](AUDIT.md)，验收和运维查 [DELIVERY](DELIVERY.md)。

## 接入与发现

独立 apps/ai-summary Worker 绑定现有 D1、R2 和 Workers AI，增加生成队列及 DLQ。已落库的 approved 资源才进入发现范围。独立 Cron 用主键游标发现新增，用有界轮巡发现存量变化和恢复上架。频道轮巡分批比较 R2 对象版本，变化才读正文。避免在现有 Bot 刷新、支付或审核请求内执行生成。

新录入频道的帖子可能还没写 R2，可先凭有实质内容的简介生成，帖子到齐后重新评估。对象缺失与临时读取失败分别记录。数据不足持久标记 skipped，资料和规则不变时不反复推理。暂停生成与关闭展示使用独立开关。

## 队列、状态及并发

消息只传引用，消费者重新读取 D1 权威状态。

```json
{"v":1,"jobId":"01J…","entryId":1234,"generation":17,"inputHash":"sha256:…"}
```

正常状态流为 pending → queued → running → succeeded、skipped、superseded、retry_wait 或 failed。D1 先提交 pending，再投队列，投递确认丢失可以重发。扫描补偿超过派发期限仍未领取的任务。通过条件更新领取任务租约，唯一尝试令牌限制提交者。每条消息独立确认，防止一个失败项拖累同批。

生成键由 entry_id、input_hash、prompt_version、model_id、output_schema_version 和 generation_params_version 组成。相同键复用成功或跳过结果，规则或模型升级形成新键。手动失败重试复用任务。

临时限流、超时和服务故障进入 retry_wait，带抖动退避，初始最多 3 次推理尝试。配额用完延到次日 UTC，暂停保留待处理任务。D1 到期扫描负责业务重试，Queues 处理传输和消费者故障，耗尽进入 DLQ 并告警。未知模型调用结果保留预算预留，租约到期后有限重试。数据库结果和发布幂等，模型已受理但保存前退出仍可能重复计费。

推理前后核对资料，提交条件包括当前来源代次、未过期租约令牌、模型策略、编辑版本、锁定和条目状态。人工编辑用版本比较，锁定撤销在途任务写回资格。资料变化保留锁定稿供复审，证据失效时公开展示回退模板。

R2 与 D1 无跨存储原子提交。生成后重读对象版本，静态构建再用实际导入帖子复核证据。新帖出现时可以继续显示仍有证据的已批准摘要，证据变更、隐藏或撤回时在下一快照回退。该边界须在并发测试中覆盖。

## 输入指纹及回填

规范化标题、原简介、类型、分类和标签 slug，以及经过可见性过滤和抽样的实质帖子证据后计算 SHA-256。排除人数、views、头像、推广、普通刷新时间。类别标签只提供语境，不能单独证明用途。短时连续变更合并处理。

历史回填先预检合格、缺资料、锁定和当前结果数量，固定 max(id)，以 id > cursor 且 id <= upper_bound 分页。初始每次 25–50 条候选，任务落库后推进游标，可暂停恢复和按类型重跑。新增任务优先，预留其配额。每天约 100 次生成机会、2,000 条均需推理时约 20 天，失败与跳过会改变工期。回填使用现有数据，不额外批量抓 Telegram。

## 提示词与结构校验

应用组装 JSON 输入，包含 kind、标题、原简介、分类标签和带 ref 的证据列表。频道初始最多 4 条有实质内容的可见帖子，每条设字符上限，去重并移除无关广告联系方式。复用静态快照的全隐藏、单帖及关键词过滤规则。各类型使用短系统规则，附一个合格示例和一个资料不足示例。

| 类型 | 专用提示词任务 |
| --- | --- |
| 频道 | 说明能阅读的内容，最多归纳两个主题。单帖只证明该帖内容，多个独立证据才概括近期主题，避免把广告或转载当作长期定位 |
| 群组 | 依公开简介提炼讨论主题，明示的条件和规则才可写。无群聊样本时省略活跃度、成员构成、答疑质量和频率 |
| 机器人 | 只写公开说明明示的功能。省略未经验证的命令、权限、费用、效果和安全承诺。启动参数不证明功能 |

```json
{"status":"ok","sentences":[{"zh":"这个频道分享开源软件的更新和使用指南。","en":"This channel shares open-source software updates and user guides.","refs":["profile","post:121"]}]}
```

资料不足返回 status=insufficient 和空 sentences。严格校验字段集合、句数、长度、语种、引用范围和受保护名称，拒绝新增链接、联系方式、命令、HTML、无依据数字和强断言。输入来源全部作为不可信数据放在独立消息，禁止执行其中指令。模型无工具、外部访问和发布权限。支持时启用结构化响应，仍需本地 Zod 校验。引用存在只证明来源可找到，事实蕴含需人工抽检。
