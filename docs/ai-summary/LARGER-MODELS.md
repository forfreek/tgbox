# 更大参数模型的小批对照

2026-11-22。用户允许效果不够时尝试更大参数模型，本轮核对Cloudflare官方目录后测试Llama 3.3 70B和gpt-oss-120B。采用COMPARISON的相同四条构造输入与研究草案system/user消息，共八次调用，无联网搜索、不改默认模型、不部署。

接口参数按提供商区分：Llama采用JSON schema、temperature=0、max_tokens=1024；GPT-OSS采用JSON object、temperature=0、max_completion_tokens=2048、reasoning_effort=low。正文规则相同，但不是所有采样参数和结构化约束完全相同的严格消融实验。没有加入人工写法示例，示例引导路线尚未验证。模型名的总参数规模不等于中文写作质量或每次激活规模。
