# 收录要求指南

内容以本站既有收录说明、Bot 帮助和用户本轮明确要求为基础。禁止内容是本站收录规则的表达，Telegram 平台规则链接为 https://telegram.org/tos 。本轮处理文案与入口，历史条目审核属于后续运营工作。
